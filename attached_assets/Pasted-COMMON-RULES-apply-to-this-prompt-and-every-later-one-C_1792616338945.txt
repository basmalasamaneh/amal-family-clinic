Goal: make the whole app look like a polished, modern, calm, formal SaaS product that is
clearly not a basic or default template. Keep every behavior identical.

1. Typography (smaller, still very clear). Arabic: IBM Plex Sans Arabic. English: IBM Plex Sans.
   Self-hosted (@fontsource), weights 400/500/600/700, included in the service worker precache.
   Scale: caption 12.5, small 13.5, table and card text 14, body 15, subheading 17, heading 20,
   page title 26, display 32. Line-height 1.7 Arabic, 1.5 English. Weights: body 400, labels 500,
   headings 600. No italics and no letter-spacing on Arabic. Tabular numbers in tables, times,
   KPIs. Add a user setting "Display density": Compact / Comfortable (default) / Large. Reception
   screens default to Large (body 16 to 17) because they run on tablets in busy mornings. The
   setting is stored per user and applies instantly.
2. Colors (tokens, Light / Dark). Keep the existing tokens (primary #0E7C86 / #3CC4CF, navy,
   bg, surface, surface-2, border, text, muted, success, warning, danger, info; gold only for

   Reception teal #0E7C86, Patients blue #2F6FB3, Network violet #6D5BD0, Admin slate #475569,
   each with a soft tint background (Light and Dark versions). Status colors never change
   meaning. Never use gold or an accent as a status color. Contrast: text 4.5:1, UI 3:1.

   dialogs. Thin borders plus very soft shadows in Light; in Dark use lighter surfaces instead

   Motion 150 to 200 ms, respects prefers-reduced-motion. lucide-react icons only, stroke 1.75,
